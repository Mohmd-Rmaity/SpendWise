# SpendWise – Personal Finance Management App

SpendWise is a personal finance management application built with React. It helps users organize their income and expenses, manage budgets, and make better financial decisions through a simple and responsive interface.

## Live Demo

[Open SpendWise](https://spendwise-big5mzv80-mohdmr138-4927.vercel.app/)

## GitHub Repository

[View the source code](https://github.com/Mohmd-Rmaity/SpendWise)

## Features

- **Dashboard:** View total balance, income, expenses, savings, and financial charts.
- **Transactions:** Add and delete income and expense transactions.
- **Budgets:** Create category-based budgets and monitor spending.
- **Financial Planner:** Check whether a purchase fits your available balance.
- **Currency Conversion:** Switch between USD and LBP using the configured exchange rate.
- **About:** Learn about SpendWise and its purpose.
- **Contact Us:** Submit a contact form.
- **Login and Signup:** Frontend demonstration of account forms.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
- **Data Persistence:** Saves transactions and budgets using browser localStorage.

## Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Mohmd-Rmaity/SpendWise.git
   ```

2. Navigate to the React application folder:

   ```bash
   cd SpendWise/client
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the application in your browser:

   `http://localhost:3000`

## Data Storage

SpendWise uses browser localStorage to save transaction and budget information. The data remains available after refreshing the page in the same browser, but it is not synchronized between different devices or users.

## Currency Exchange Rate

The application uses a configured exchange rate:

**1 USD = 89,500 LBP**
